# Road Damage Detection

A Python-based Digital Image Processing project to detect potential road damage, such as cracks and potholes, using OpenCV.

# Technologies
- Python
- OpenCV
- NumPy
- Matplotlib

# Features
- Grayscale conversion
- Noise removal
- Image enhancement
- Edge detection
- Damage region detection

# How to Run
1. Install the required libraries.
2. Add a road image as `road.jpg` inside `dataset/images/`.
3. Run `main.py`.

# Output
Displays the processed image with suspected damaged regions highlighted.
